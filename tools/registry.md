# Tool Registry

## 세 가지를 구분합니다

| 구분 | 뜻 | 이 저장소에서의 상태 |
| --- | --- | --- |
| Local Tool | 파일 읽기·검색처럼 Codex 실행 환경이 제공하는 기능 | 문서 확인에만 사용 |
| MCP Server | 외부 시스템의 Tool과 Context를 제공하는 연결 서버 | 기본값은 미연결 |
| MCP Tool | 연결된 MCP Server가 공개한 개별 조회·실행 기능 | 실제 연결 후 허용 목록에서 선택 |

MCP Server 연결은 `.codex/config.toml`에 작성합니다. `AGENTS.md`와 `SKILL.md`는 연결 정보를 등록하는 파일이 아닙니다.

## Tool을 추가할 때 기록할 항목

- Tool 이름과 제공 주체
- 입력값과 반환값
- 조회 전용인지 외부 상태를 변경하는지
- 자동 실행·사람 확인·실행 금지 중 어느 범위인지
- 실패했을 때 재시도할지 중단할지

현재 예시는 패턴 구조를 보기 위한 문서형 저장소이므로 실제 외부 MCP Tool을 호출하지 않습니다.

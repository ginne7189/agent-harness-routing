# 이 저장소의 학습 범위

이 저장소는 하나의 Workflow 패턴이 Harness 파일에 어떻게 나뉘어 표현되는지 확인하기 위한 구조 예시입니다.

- 실행 코드는 포함하지 않습니다.
- `AGENTS.md`에서 전체 목표와 공통 규칙을 확인합니다.
- `workflow.md`에서 패턴의 실행 순서와 종료 조건을 확인합니다.
- `roles/`에서 역할별 책임을 확인합니다.
- `contracts/`에서 역할 사이 전달 형식을 확인합니다.
- `policies/`에서 자동 실행과 사람 확인 경계를 확인합니다.
- `tools/`에서 Local Tool·MCP Server·MCP Tool을 구분합니다.
- `.agents/skills/`에서 Codex가 따라야 할 반복 업무 순서를 확인합니다.
